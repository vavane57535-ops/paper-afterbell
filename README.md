# Paper Afterbell

Jeu de survie asymétrique dans une école de papier (Godot 4.5.1, rendu GL Compatibility).

Ouvrir le dossier avec **Godot 4.5.1** (`project.godot`). Les notes de version, crédits et licences sont dans `docs/`.

Les sources ont été reconstruites à partir de l'export Windows 0.15 (scripts décompilés : les commentaires d'origine ne sont pas conservés).
